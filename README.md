# TypeScript Learning Journey

This repository contains my TypeScript learning journey as I explore the core concepts of the language through practical examples and hands-on practice.

## Overview

The repo is organized by topic, with each file focusing on a specific TypeScript concept:

### Basics
- `basics/introduction.ts` – introductory TypeScript examples and syntax
- `basics/types-and-interfaces.ts` – type annotations, primitive types, and interfaces

### Functions
- `Functions/function-types-rest-overloading.ts` – function types, rest parameters, and function overloading

### Generics
- `Generics/generics.ts` – generic types and reusable components

### Object-Oriented Programming
- `OOP/classes-access-modifiers.ts` – classes and access modifiers
- `OOP/classes-advanced.ts` – advanced class concepts and OOP patterns

### Type Guards
- `TypeGuards/type-assertions-and-guards.ts` – type assertions and type guard techniques

## Purpose

This repository serves as a personal learning log where I practice and document key TypeScript ideas such as:
- strong typing
- interfaces and types
- functions and generics
- classes and OOP
- type narrowing and guards

## How to Use

Each file can be opened and studied individually as a standalone example of a TypeScript topic.

## Notes

This project is a work in progress and will continue to grow as I learn more about TypeScript.
